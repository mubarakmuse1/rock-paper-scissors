# Rock, Paper, Scissors Game

This is a simple Rock, Paper, Scissors game I built using HTML, CSS, and JavaScript. You can play against the computer, choose your move, and see who wins each round.

I created this project to practice my JavaScript skills and learn how to make a website interactive.

## Features

- Play against the computer.
- Choose between Rock, Paper, and Scissors.
- The computer randomly picks its move.
- See who wins, loses, or gets a draw.
- Keep track of your score and the computer's score.
- Reset the game whenever you want.
- Works on mobile phones, tablets, and computers.

## How to Play

1. Open the game in your browser.
2. Choose Rock, Paper, or Scissors.
3. The computer will randomly choose its move.
4. The game will show the result.
5. Keep playing and try to beat the computer!

### Game Rules

- Rock beats Scissors.
- Paper beats Rock.
- Scissors beats Paper.
- Choosing the same option results in a draw.

## Technologies Used

- HTML – To build the structure of the game.
- CSS – To style the game and make it responsive.
- JavaScript – To handle the game logic, scores, and results.
